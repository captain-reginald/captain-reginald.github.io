Rain Log

One rainfall journal, three places to keep it. Enter the day's gauge reading in tenths of an inch; Rain Log holds the totals for 24 hours, the week, the month, the season, the year. Everything is one rainlog.json you can sync, back up, or read by hand.

01Omarchy Rain Log

Bar plugin, Omarchy 4.x GPL-3.0 github.com/captain-reginald/omarchy-rain-log

A raindrop in the bar, with the card behind it. Today's reading sits at the top; below are totals for 24 hours, 72 hours, the week, the month, the season, and a custom window (14 days by default). The arrows step any total back in time, and Edit History is a month calendar for missed days and typos.

Readings match a US gauge: 23 means 2.3 inches, and zero clears the day.

# install
omarchy plugin add https://github.com/captain-reginald/omarchy-rain-log --enable

# without --enable, or to move it on the bar
omarchy plugin enable io.github.captain-reginald.rainlog

# later
omarchy plugin update io.github.captain-reginald.rainlog

02Rain Log Server

Self-hosted web app v1.0.0 github.com/captain-reginald/rainlog-server releases

The big-screen and phone view of the same file. Configurable totals windows, month, season and year, charts against your area's 1991–2020 climate normals, calendar editing, CSV and JSON import/export with a dry run, automatic snapshots. It installs as a PWA, and readings always come from the server rather than a cache.

git clone https://github.com/captain-reginald/rainlog-server.git
cd rainlog-server
docker compose up -d
# open http://<host-ip>:8080

Or pull ghcr.io/captain-reginald/rainlog-server:latest — tags v1.0.0, 1.0 and main, for amd64 and arm64. The compose file defaults to PUID=1000, PGID=1000 and America/Denver; set your own before the first start.

03Rain Log Desktop

Linux and Windows app v1.0.0 github.com/captain-reginald/rainlog-desktop latest release

The plugin's card as an ordinary window, for desktops that aren't Hyprland and for Windows. Frameless, no tray icon; closing saves and quits. It follows the Omarchy theme on Linux, falls back to a bundled palette elsewhere, and adopts the plugin's data path on first run.

From the v1.0.0 release: RainLog-v1.0.0-linux-x86_64.AppImage (chmod, run) or RainLog-v1.0.0-windows-x64.exe for Windows 10 x64. SHA-256 sums sit beside each download.

# optional: put the AppImage in the application menu
chmod +x RainLog-v1.0.0-linux-x86_64.AppImage
./RainLog-v1.0.0-linux-x86_64.AppImage --install

# and, if you change your mind
~/Applications/RainLog-Desktop.AppImage --uninstall

On Hyprland, windows tile by default. To keep Rain Log floating like the plugin card:

# ~/.config/hypr/hyprland.lua
hl.window_rule({ name = "rainlog-desktop", match = { class = "rainlog-desktop" }, float = true })

04How they fit together

All three write the same rainlog.json, atomically and in two-space sorted JSON, so a synced folder — Syncthing, Resilio, a git repo — keeps every device current. The plugin watches the file; the server re-reads it every five seconds and, before writing, merges just the days it changed.

Two devices writing at once is the only real way to lose a reading, so let sync settle before editing from the other side. Web-only settings and cached normals live in their own files beside the JSON.

05The file

Default path is ~/Documents/rainlog/rainlog.json. The plugin's setting takes precedence, and the desktop app adopts it on first run.

{
  "entries": {
    "2026-11-14": 23,
    "2026-11-15": 12
  }
}
  • Tenths of an inch, keyed by local date. 23 is 2.3 inches.
  • No key means no rain; entering 0 deletes the day.
  • Two-space JSON, sorted keys, so diffs stay small in sync.
