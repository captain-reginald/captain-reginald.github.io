I run a small homelab on Omarchy and Linux, and most of what I build stays close to home: plain files, self-hosted services, no accounts, no telemetry. When something turns out to be useful to other people, it goes on GitHub.

01Rain Log

The web dashboard. The plugin and the desktop app show the same numbers.

My rain gauge, minus the guesswork

Rain Log turns the number on a backyard rain gauge into rolling totals you can plan around: the week, the month, the season. Three releases, one shared rainlog.json — an Omarchy bar plugin, a self-hosted web app, and a desktop companion for everything that isn't Hyprland.
